# 竞品调研与自研取舍

> 结论先行：自用场景不需要第三方协议兼容，filex 采用**自研对象存储协议 v1**，
> 吸收主流对象存储的分片、校验、版本化、元数据、列表分页等优点，
> 去掉多节点一致性、协议兼容层与运维复杂度，专注单机/单盘、可备份、
> 可观测、可审计的轻量对象存储组件。

## 1. 竞品盘点

| 方案 | 定位 | 协议 | 亮点 | 自用场景的负担 |
| --- | --- | --- | --- | --- |
| MinIO | 单机/集群 S3 对象存储服务 | S3 | 生态成熟、分片上传、版本化、SSE、生命周期、Web UI | 独立服务进程；S3 XML 兼容层与多租户/策略体系偏重；配置面大 |
| SeaweedFS | 分布式 blob/对象存储 + S3 网关 + Filer | S3 / 私有 | 海量小文件、O(1) 寻址、云分层 | master/volume/filer 多组件；元数据依赖外部数据库；自用单机收益低 |
| Ceph RGW | 统一存储的对象网关 | S3 / Swift | 生产级可靠性、多站点 | 部署运维复杂度最高，明显超出自用规模 |
| Garage | 自托管分布式对象存储 | S3 | 轻量、跨节点复制、块去重、Zstd 压缩 | Rust 独立服务；为多节点容灾设计，单机自用偏重 |
| minio-go / aws-sdk-go-v2 | S3 SDK | S3 | API 全、分片自动管理 | SDK 绑定 S3 语义与签名体系，引入大量依赖 |
| 通用文件工具库（afero 等） | 文件系统抽象 | 无 | 统一 FS 接口 | 不解决对象模型、校验、并发语义与传输 |

## 2. 竞品可取之处

- **分片上传与断点续传**：大对象可靠传输的基础（MinIO/S3）；
- **对象版本化与软删除**：误删可恢复（S3 / MinIO）；
- **ETag / 完整性校验**：内容寻址式防损坏（各对象存储共同实践）；
- **列表分页与前缀/分隔符**：海量键的枚举与“目录感”浏览（S3 ListObjectsV2）；
- **元数据与内容类型**：对象自带描述信息，应用无需旁路数据库；
- **服务端加密（SSE）**：静态数据保护（S3 / MinIO / SeaweedFS）；
- **生命周期管理**：过期自动清理（S3 / MinIO）；
- **配额与审计**：可控、可追溯（Ceph RGW / MinIO）；
- **可观测**：指标、请求 ID、结构化日志（各商业版均有）。

## 3. 自研结论

现成方案都要么绑定 S3 协议与独立服务，要么以分布式多节点为前提。
自用单机/小规模场景，真正需要的是：

- **一个 Go 模块**：库形态嵌入程序（服务、CLI、桌面工具），不跑独立服务；
- **协议自描述**：JSON 控制面 + 二进制数据面，规则简单、可手工调试；
- **传输层复用底座**：直接挂 `net/http` 或 webx（HTTP/1.1 / HTTP/2 / HTTP/3），
  不重复造传输栈；
- **存储布局可理解**：普通目录 + JSON 元数据，删库不靠“魔法”，可备份可迁移；
- **完整性内建**：写入即 SHA256，读取可复验，损坏可检测；
- **安全默认**：原子写、路径隔离、大小上限，加密与鉴权按版本演进；
- **全链路中文语义**：errx 错误码 + logx 结构化日志，与既有拼图一致。

## 4. 协议设计取舍

### 4.1 为什么不用 S3 / OSS / WebDAV

- 兼容层本身有成本：XML 解析、签名算法、错误语义、历史怪癖；
- 自用两端都是自己的代码，没有“第三方客户端接入”需求；
- 自研协议可以把“必须字段、校验规则、错误码、扩展点”一次定清，
  让服务端与客户端同源演进。

### 4.2 为什么基于 HTTP 而不是裸 TCP

- 复用 Go 标准库 / webx / httpx 的 TLS、HTTP/2、HTTP/3、超时、连接池；
- 控制面（JSON）与数据面（body）天然分离，抓包、调试、代理都方便；
- 分片上传可用 HTTP 语义表达（上传 ID + 部件号 + 校验和）。

### 4.3 与既有底座的分工

| 底座 | 分工 |
| --- | --- |
| errx | 全部错误码、Kind 分类、HTTP 状态映射、错误 JSON |
| logx | 操作审计与结构化日志 |
| metricsx | 指标打点（可注入） |
| webx | 协议服务端挂载（HTTP/3 等） |
| httpx | 协议客户端传输（HTTP/3 等） |
| authx | 可选鉴权（v0.5.0 起） |
